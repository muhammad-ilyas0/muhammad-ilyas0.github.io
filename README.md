## Publish with GitHub Pages
1. Create a public GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and the `images` folder.
3. Open repository Settings → Pages.
4. Choose Deploy from a branch, select `main` and `/ (root)`, then Save.
5. Wait for deployment and open the published URL.

Review all personal details and links before publishing. Only publish contact details you are comfortable making public.
